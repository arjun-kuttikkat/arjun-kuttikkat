## System Architecture

```
Client (Next.js App Router)
        ↓
Streaming API Routes
        ↓
Execution Engine
        ↓
Supabase (Auth + Postgres + RLS)
        ↓
Storage + Edge Functions
```

Infrastructure:
- Vercel production deployments
- GitHub Actions CI/CD
- Environment separation (Preview / Production)
- Versioned releases
