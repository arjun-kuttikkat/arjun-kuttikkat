## Primary Build

### Edgaze  
AI workflow infrastructure for creators.

A production system for building, publishing, running, and monetizing AI workflows.

**Core Systems**
- Node-based visual workflow engine  
- Structured placeholder mechanics  
- Streaming execution pipeline  
- Multi-tenant Supabase backend with Row-Level Security  
- Canonical workflow URLs  
- Versioned releases  

Live → https://edgaze.ai

**Architecture**

```
Client (Next.js App Router)
        ↓
Streaming API Layer
        ↓
Execution Engine
        ↓
Supabase (Auth + Postgres + RLS)
        ↓
Storage + Edge Functions
```
